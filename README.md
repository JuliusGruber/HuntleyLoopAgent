This project was a test run for [HuntleysLoop](https://github.com/JuliusGruber/HuntleysLoop), an implementation of [ralphWiggums loop](https://github.com/ghuntley/how-to-ralph-wiggum).

## How it was built

The agent was built entirely by HuntleysLoop with no human intervention:

1. **2 rounds of spec & plan loops** — to define the architecture and requirements
2. **10 rounds of build (ralph) loops** — to implement the full coding agent

The result is a fully working coding agent powered by the Anthropic API, capable of reading/writing files, running shell commands, and iterating autonomously on tasks.
